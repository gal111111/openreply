# 第一個活動文案：「留言 Open → 私訊教學連結」

這份文案配合 OpenReply 的活動（Campaign）設定使用。欄位名稱與限制都是對照程式碼確認過的（`app/api/automations/route.ts`、`lib/queue/dm-worker.ts`、`lib/tracking/message.ts`、`lib/utils/keyword-matcher.ts`），不包含程式不支援的功能。

## 先看：程式實際支援什麼

| 設定 | 程式實際行為 | 對文案的影響 |
| --- | --- | --- |
| 私訊內容 `dmMessage` | **一個活動只有一則**，上限 1000 字 | ⚠️ **程式不會自動輪流**。下面 3 個版本要由你**手動替換**（見第 1 節的輪替方式） |
| 連結按鈕文字 `linkButtonLabel` | 上限 **20 字元** | 按鈕文字要短 |
| 連結網址 | 在活動表單的連結欄位填（`trackedDestinationUrl`），會自動變成追蹤連結 `https://<你的-railway-網域>/r/xxxx` | 連結是**另外做成按鈕**，不是寫在文字裡 |
| 連結佔位符 | 程式認的是 **`{link}`**（不分大小寫，`{LINK}` 也可以） | 有按鈕時，`{link}` 會從文字中**自動拿掉**；只有按鈕被 Meta 拒絕時，才會把連結直接放進文字。所以把 `{link}` 放在句尾最安全 |
| 稱呼 `{username}` | 換成對方的 IG 帳號名稱；**抓不到名稱時會換成英文 `there`** | 句子要寫成換成 `there` 也不會太怪，例如「嗨 {username}」→「嗨 there」尚可接受 |
| 公開回覆 `publicReplyMessages` | 最多 **10 則**，每次**隨機挑一則** | ✅ 5 個版本可以全部填進去，程式會自動輪流 |
| 先追蹤才給連結 `requireFollow` | 開啟後先送「追蹤提示」＋一個按鈕；對方按下按鈕後程式檢查是否已追蹤，已追蹤才送連結，未追蹤會再提示一次。Instagram 沒回傳追蹤狀態時，直接送連結（不會卡住真的追蹤者） | 提示文案 `followPromptMessage` **只有一則**（上限 1000 字），按鈕文字 `followPromptButtonLabel` 上限 **20 字元** |
| 關鍵字 `keywords` | 最多 **10 個**，每個 50 字元內；**不分大小寫**；比對前會去掉 emoji 和標點 | 見第 4 節 |
| 整字比對 `wholeWordMatch` | 預設開啟，**整個活動共用一個設定**，不能每個關鍵字各自設定 | 見第 4 節 |

## 1. 私訊內容（3 個版本，手動輪替）

每則都在 150 字以內，按鈕文字在 20 字元以內。`{link}` 放在句尾：正常情況會被拿掉、改用按鈕；萬一按鈕被拒絕，連結會出現在這個位置。

### 版本 A

**私訊內容：**

```
嗨 {username}～謝謝你留言！教學連結整理好了，點下面的按鈕就能打開 👇 有看不懂的地方直接回我訊息就好，我看到會回你 🙌 {link}
```

**按鈕文字：** `打開教學`

### 版本 B

**私訊內容：**

```
{username} 你好！收到你的留言了～這是你要的教學，步驟都寫在裡面，照著做應該 10 分鐘內就能搞定。卡住的話歡迎回來問我 😊 {link}
```

**按鈕文字：** `看教學`

### 版本 C

**私訊內容：**

```
哈囉 {username}，來送教學了 ✨ 連結在下面，建議先存起來慢慢看。如果覺得有幫助，也很歡迎跟我分享你做出來的成果！{link}
```

**按鈕文字：** `點我看教學`

### 怎麼輪替（程式不會自動換）

- **建議做法：每篇貼文用一個版本。** 每篇新貼文建一個新活動時，換下一個版本（A → B → C → A…）。
- 或者同一個活動每隔幾天進去改一次私訊內容。
- 避免被判定為垃圾訊息的重點：每則都有稱呼對方、內容回應了對方的要求（對方主動留言要的）、不放多個連結、不用大量 emoji 或全形驚嘆號、不催促。

## 2. 公開回覆（5 個版本，程式自動隨機挑）

把 5 則全部填進活動的「公開回覆」清單（最多可填 10 則），並開啟公開回覆。每次觸發時程式會隨機挑一則，自然避免每則一字不差。公開回覆也支援 `{username}`。

```
已私訊你囉 👀
```

```
{username} 教學傳過去了，記得看一下私訊～
```

```
收到！連結在你的私訊裡 📩
```

```
傳給你了～有問題再跟我說 🙌
```

```
去私訊找找看，教學在那邊等你 ✨
```

> 提醒：公開回覆**不要放連結**，連結只走私訊。

## 3. 「先追蹤才給連結」提示（2 個版本）

⚠️ 程式只有**一個**提示欄位，這 2 個版本請擇一使用，或像私訊一樣手動輪替。按鈕文字在 20 字元以內。

對方按下按鈕後，程式會檢查是否已追蹤：已追蹤就送出第 1 節的私訊＋連結按鈕；還沒追蹤會再提示一次。

### 版本 A

**提示內容：**

```
嗨 {username}！教學馬上給你～想請你先追蹤我一下，之後有新教學你也不會錯過。追蹤好之後按下面的按鈕，我就把連結傳給你 🙏
```

**按鈕文字：** `我追蹤好了`

### 版本 B

**提示內容：**

```
{username} 你好～送教學前有個小請求：先追蹤我的帳號，再點下面按鈕，連結就會自動傳過來囉 😊
```

**按鈕文字：** `已追蹤，傳給我`

## 4. 關鍵字設定

### 程式怎麼比對

- **不分大小寫**：`open`、`Open`、`OPEN`、`oPeN` 全部視為同一個字。所以只要填 `open` 一個就夠，不用把大小寫變體都填進去（關鍵字最多只能填 10 個，省下名額）。
- 比對前會先去掉 emoji 和標點符號，所以「Open!!」「open 🙏」「開～」都能正常比對。
- 多個關鍵字是「任一個符合就觸發」。

### 整字比對 vs 部分比對

| | 整字比對（預設，建議） | 部分比對 |
| --- | --- | --- |
| `open` | 「open」「Open please」「OPEN!!」✅；「opened」「reopen」❌ | 「opened」「reopen」「opening」也會觸發 |
| `開` | 單獨留「開」「開！」「開 🙏」✅；「我要開」❌ | 「開心」「打開」「開箱」「好開」都會觸發 ⚠️ |
| `要` | 單獨留「要」「要！」✅；「我要」❌ | 「不要」「需要」「重要」「要不要」都會觸發 ⚠️ |

**建議：開啟整字比對。**

原因：中文字之間沒有空格，所以在整字比對下，中文關鍵字只有在**單獨出現**（或前後是空格、標點、emoji）時才會觸發。這雖然會漏掉「我要開」這類留言，但部分比對的誤觸發更嚴重：「要」會命中「不要」「需要」，「開」會命中「開心」，等於把私訊亂發給沒要求的人，也更容易被 Instagram 判定為垃圾訊息。

整字比對會漏掉句子裡的中文，所以用「多填幾個常見說法」來補。

### 建議填入的關鍵字（共 7 個，上限 10 個）

```
open
開
要
我要
想要
求
+1
```

說明：

- `open`：已涵蓋 Open、OPEN 等所有大小寫。
- `開`、`要`：對方只留一個字的情況。
- `我要`、`想要`、`求`：中文留言常見說法，整字比對下要單獨留才會觸發。
- `+1`：比對前會去掉 `+` 號，實際比對的是「1」。整字比對下，單獨留「+1」或「1」會觸發，「10」「100」不會。如果擔心誤觸發可以不填。
- 貼文文案建議明確寫「留言 **Open** 我私訊你教學」，引導大家留一樣的字，觸發最穩定。

### 可以不用關鍵字嗎？

活動有「任何留言都觸發」（`matchAnyWord`）的選項，但**不建議**第一個活動使用：所有留言（包括單純稱讚、問問題）都會收到私訊，容易被當成洗版。
